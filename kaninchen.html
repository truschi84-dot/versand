        📲 App aufs Handy

        Als eigene App installieren – alle Einträge bleiben (Cloud + dein Name auf dem Gerät).

        So geht’s – Android & iPhone

        Wichtig: Installieren oder „Zum Home-Bildschirm“ löscht keine Daten. Die gemeinsame Liste liegt in der Cloud; dein Name ist lokal auf dem Handy gespeichert. Einfach dieselbe Seite wie im Browser nutzen – nicht die App deinstallieren und neu anfangen, wenn du weiter eintragen willst.

        Android (Chrome)

        1. Seite in Chrome öffnen (Link aus WhatsApp).
        2. Oben auf „App installieren“ tippen – oder Menü ⋮ → App installieren / Zum Startbildschirm hinzufügen.
        3. App über das neue Kaninchen-Icon starten (grüner Hintergrund mit Hase).

        iPhone (Safari)

        1. Link in Safari öffnen (nicht nur in WhatsApp-Vorschau).
        2. Unten Teilen (Viereck mit Pfeil) → Zum Home-Bildschirm.
        3. Name z. B. Kaninchen → Hinzufügen.

        Am PC: Seite normal im Browser lassen – Installation ist nur fürs Handy sinnvoll.
