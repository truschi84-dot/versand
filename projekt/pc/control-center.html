📖 Kurz-Anleitung

  1. Desktop-Icon (einmal): Control-Center-Desktop.bat im Ordner scripts
  2. Jede Session: Doppelklick Desktop-Verknüpfung oder Control-Center-Starten.bat
  3. Büro + USB: Handy anschließen → „Web kopieren + installieren“
  4. Alle Handys remote: „Version +1 und auf GitHub veröffentlichen“ → Handy „App-Update prüfen“
  5. Nach Urlaub: Ordner aufräumen – projekt/docs/ROADMAP-NACH-URLAUB.md
