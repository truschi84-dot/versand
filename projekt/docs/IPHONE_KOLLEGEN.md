## Text zum Kopieren (WhatsApp / E-Mail)

```
Tresch Kombi-App auf dem iPhone einrichten

1) Diesen Link in SAFARI öffnen (nicht nur in Chrome):
https://truschi84-dot.github.io/versand/index.html

2) Unten auf „Teilen“ tippen (Viereck mit Pfeil nach oben)

3) „Zum Home-Bildschirm“ wählen (oder „Zum Bildschirm“)

4) Name z. B. „Kombi App“ → Hinzufügen

5) Ab jetzt die App nur noch über das Icon auf dem Startbildschirm öffnen – nicht über ein altes Lesezeichen.

   (Neues Firmen-Logo: altes Icon vom Home-Bildschirm löschen, Schritte 1–4 noch einmal.)

─── Wenn es ein App-Update gibt (Bescheid vom Büro) ───

6) App öffnen → Menü ☰ → „App-Update prüfen“
   • Steht „App ist aktuell“ → nichts tun
   • Kommt „Neues Update“ → „Jetzt installieren“ tippen

Internet (WLAN oder Mobilfunk) muss an sein. Cloud/Backup wie gewohnt über ☁️.

Fragen: [DEINE TELEFONNUMMER / ANSPRECHPARTNER]
```

| Thema | Hinweis |
